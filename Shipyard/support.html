Common questions

Do I need an account? No. Shipyard has no account system. You can skip GitHub on the first screen and add apps by hand.

What GitHub token should I create? A fine-grained personal access token from GitHub's settings (Developer settings > Personal access tokens > Fine-grained tokens), limited to the repositories you want in Shipyard, with read-only access to Contents, Issues, Pull requests and Metadata. Add read-only Checks and Commit statuses if you want "In Review" to require passing CI. Shipyard never writes to GitHub.

How do I connect App Store Connect? In App Store Connect, go to Users and Access > Integrations > App Store Connect API and create a key; the App Manager role is enough. In Shipyard, link an app's store listing and paste the Issuer ID, Key ID and the contents of the .p8 file. Shipyard only reads.

Why isn't a pull request moving its card? Cards follow the pull request's state: draft goes to Building, open to Planning, a testing label to Testing, approved with passing checks to In Review, merged to Live, closed without merging to Parked. If you drag a card yourself, Shipyard leaves it where you put it until the pull request changes again.

I see an "offline", "expired" or "rate-limited" banner. Shipyard keeps showing your cached data. "Expired" or "revoked" means the token or key needs replacing from the menu; "rate-limited" clears on its own once GitHub's limit resets.

Do my iPhone and desktop sync? Not yet. Each device keeps its own data. You can move boards between devices with Export and Import in Settings.

Where is my data? On your device only. See the privacy policy.
